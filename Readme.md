## Cómo abrir los archivos para corregirlos

Para corregir el documento manteniendo su formato, puede descargar [Grupo_03_ejercitacion.docx](Grupo_03_ejercitacion.docx) y abrirlo con **Microsoft Word**, **Google Docs** o **LibreOffice Writer**.

En Google Docs, debe ingresar a [Google Drive](https://drive.google.com/), seleccionar **Nuevo > Subir archivo**, elegir el archivo `.docx` y luego abrirlo con **Documentos de Google**. Una vez realizadas las correcciones, puede guardarlo nuevamente como `.docx` desde **Archivo > Descargar > Microsoft Word (.docx)**.

También puede abrir [Grupo_03_ejercitacion.md](Grupo_03_ejercitacion.md) directamente en GitHub o Visual Studio Code. Esta versión es solo para lectura y corrección del contenido en Markdown; no conserva el formato visual del documento de Word.

**Importante:** no se debe abrir el archivo `.docx` directamente con Visual Studio Code ni con la extensión de Python, porque se mostrará como texto ilegible. El formato `.docx` es un archivo binario comprimido.
